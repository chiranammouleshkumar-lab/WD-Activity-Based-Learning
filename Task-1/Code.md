# 🛍️ ShopEase – Online Shopping Website

**ShopEase** is a responsive online shopping website built using HTML, CSS. It provides a simple and user-friendly shopping experience where users can explore products, browse categories, search for items, and add products to their shopping cart.

## ✨ Features

- Responsive and attractive user interface.
- Navigation bar with Home, Categories, Products, and Contact sections.
- Product search functionality.
- Category-based product filtering.
- Product cards with images, ratings, prices, and discounts.
- Add to Cart functionality.
- Shopping cart with total price calculation.
- Promotional shopping banner.
- Responsive design for desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling, layouts, animations, and responsive design.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the ShopEase website.
