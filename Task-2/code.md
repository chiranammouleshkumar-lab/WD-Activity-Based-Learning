# 🏡 DreamHome – Real Estate Website

**DreamHome** is a responsive real estate website designed using **HTML5 and CSS3**. It provides a clean and user-friendly interface for exploring houses, apartments, and rental properties.

The website showcases property listings with images, prices, locations, amenities, and property details.

## ✨ Features

- **Navigation Bar** – Easy navigation between website sections.
- **Hero Section** – Attractive homepage with a modern house image.
- **Property Listings** – Displays six different properties.
- **Property Details** – Expandable details using HTML `<details>` and `<summary>`.
- **Search Interface** – Property search fields and filter dropdowns (visual only).
- **Comparison Table** – Displays property information side by side.
- **Contact Section** – Provides email contact information.
- **Responsive Design** – Supports desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Explore the DreamHome website.

## 🎯 Project Objective

The main objective of this project is to develop a simple and attractive real estate website using HTML and CSS without using JavaScript.

It demonstrates HTML structure, CSS styling, responsive layouts, navigation links, property cards, and tables.

## ⚠️ Limitations

- Property search and filtering are currently visual only.
- Property comparison is displayed using a static table.
- No backend or database integration is included.
